# 🛍️ TrendVerse — Modern E-Commerce Store
**TrendVerse** is a modern, clean, and fully responsive front-end e-commerce web application crafted with vanilla HTML5, CSS3, and JavaScript. Designed with contemporary UI/UX patterns, it features modern glassmorphism headers, product quick-view modals, interactive cart counters, and smooth horizontal sliders.

## ✨ Features

- 🎨 **Modern Aesthetics:** Sleek layout with custom color tokens, smooth hover micro-interactions, and high contrast typography.
- 📱 **Fully Responsive Layout:** Optimized using CSS Grid and Flexbox for mobile, tablet, and desktop viewports.
- 🛍️ **Interactive Quick View Modal:** Click on any product to view details in a smooth popup overlay without leaving the page.
- 🛒 **Dynamic Cart Counter:** Real-time badge counter updating when items are added to the shopping bag.
- 🎠 **Horizontal Product Slider:** Custom touch/click scrollable carousel for limited edition items.
- 🍔 **Mobile Navigation Drawer:** Clean toggle menu for seamless mobile user navigation.
- 🔍 **Instant Search Bar UI:** Stylish input bar for product and category search queries.

---

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic Elements)
- **Styling:** Custom CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism, Animations)
- **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Event Handling)
- **Icons & Fonts:** FontAwesome v6.5.1 & Google Fonts (Poppins)
